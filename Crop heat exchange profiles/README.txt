Authors: Mathieu Laroche, Danielle Monfet & Katherine D'Avignon

Description of the files

This file contains heat exchange profiles for lettuce cultivated in Quebec .

The heat exchange values were generated using the steady-state lettuce model integrated in a small-scale greenhouse model. Values were generated for 3 Quebec cities (Montreal, Baie-Comeau & Kuujjuaq) and 4 indoor temperatures (5, 10, 15 & 20°C). Heat exchange values are to be implemented as a schedule, where every month is represented by a type-day. 

The profiles are to be used in lieu of the dynamic model when crop model implementation is not possible.
